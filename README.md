# Zuch
Class 8 se Mastery tak: Practice, Quiz, Progress. Languages: English + سنڌي.

## GitHub par mobile se lagane ke steps
1. github.com par new repository banao (naam: `zuch`, Public).
2. "Add file" > "Upload files" me ye 4 files daalo: index.html, manifest.json, logo.jpg, README.md. Commit karo.
3. Settings > Pages > Branch: `main` / `(root)` > Save.
4. 1-2 minute baad link: https://USERNAME.github.io/zuch/
5. Phone browser me kholo > menu > "Add to Home screen".
